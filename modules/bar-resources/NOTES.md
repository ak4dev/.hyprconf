## Cross-module facts

- The four bar modules share one shape (link → rescan → discovery poll → enable once → marker). The poll and the `.bak` move are copied into each on purpose — a single module directory has to run on its own.
- The marker keeps its legacy name, `~/.local/state/hyprconf/resources-applied`, so an already-installed box does not re-enable a widget the user disabled.
- `sync_plugin_dir`'s exec-bit self-heal has no successor: with a link, the mode in the checkout *is* the mode the shell execs. `test_the_feeders_ship_executable` pins the checkout side; the shared publishable-shape test in `test_plugins.py` pins it for every plugin once repointed.
- This module installs no packages and needs no `sudo`, so it has no `HYPRCONF_NO_SUDO`/TTY branch; it exits 0 without a running shell and enables on the next run.
- `omarchy-plugin-validate` is pinned **inside the module**: `test_the_installed_folder_passes_omarchy_plugin_validate` installs into the box and runs the real validator on the installed link, asserting it passes with the trailing slash and refuses without it (`bin/omarchy-plugin-validate:115`). It is the module's own CI skip (no Omarchy there) — count it when you reconcile AGENTS' "exactly one test skips in CI" line, and it does **not** replace the repo-wide port in `tests/unit/test_plugins.py` (brief decision 12), which covers every plugin folder.
- `plugin/Widget.qml`'s `Cell` comment used to cite "stock 4.0.2" for the PlainText hardening; it now cites the 4.0.3-1 file it rests on (`plugins/bar/widgets/ActiveWindow.qml:32`), so no 4.0.2 string survives in this module. The other bar modules may carry the same stale reference.
- `omarchy-shell shell rescanPlugins` runs on **every** run, as in the brief's `bar-clock` reference: it re-reads what is on disk and writes nothing, and with a symlinked folder it is the only thing that carries a `git pull` into the running bar. "Byte-stable" is therefore pinned as *writes nothing and re-enables nothing* (`test_a_second_run_writes_nothing_and_re_enables_nothing`, which compares every file, symlink target and mtime under `$HOME`).
