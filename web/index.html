.hyprconf

Hyprland Configuration Suite

A complete Arch Linux + Hyprland configuration: one command from a live ISO to a fully encrypted, themed, hardened desktop. 68 themes applied across the whole system, a unified CLI and terminal UI, hardware auto-detection, and privacy-hardened defaults out of the box.

This is a personal Hyprland setup, shared openly as reference and inspiration. Fork it, take what's useful. Offered as-is — feature requests and issues may not be taken.
