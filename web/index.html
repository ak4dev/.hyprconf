.hyprconf

Hyprland Configuration Suite

A complete configuration suite for Arch Linux and Hyprland. Manage 68 themes, keybinds, window rules, monitor layouts, and system settings through a CLI, a rich terminal UI, or a one-command install — with privacy-hardened defaults out of the box.

This is a personal Hyprland setup, shared openly as reference and inspiration. Fork it, take what's useful. Offered as-is — feature requests and issues may not be taken.

What it does

Theme engine

68 themes spanning community favorites and AI-generated originals. One command cascades colors instantly across Hyprland, Kitty, Waybar, VS Code, Firefox, and hyprlock.

Keybindings

Production-ready bindings for window management, workspaces, app launching, media, and displays — fully editable through the CLI or TUI.

CLI & TUI

A full CLI and interactive terminal UI for every part of the environment: themes, keybinds, window rules, monitors, lock screen, idle, and wallpapers.

Installation

Three modes: a complete Arch install from a live ISO, dotfiles-only for an existing Hyprland system, or the standalone CLI.

Hardware detection

Automatic config for touchscreens, convertibles, accelerometers, mechanical keyboards, Nvidia GPUs, and GPU passthrough (VFIO) — applied at install and kept current via sync.

Monitor profiles

Define and switch multi-display presets — resolution, scaling, position, and transforms per profile — instantly via keybind or TUI.

Private browsing

Firefox ships hardened: enterprise privacy policies, uBlock Origin, telemetry off, theme-matched. LibreWolf is one command away; both auto-themed.

VPN & kill-switch

Manage any NetworkManager VPN (OpenVPN or WireGuard) from the CLI and a waybar indicator, with an opt-in fail-closed kill-switch.

Lock & idle

Theme-aware hyprlock lock screens with configurable idle timeouts, DPMS management, and automatic suspend — all from the CLI.

YubiKey login

Optional FIDO2 + PIN hardware-key auth for sudo, TTY login, display manager, SSH, and LUKS unlock at boot — enrolled by one interactive, self-rolling-back script.

Sync & update

hyprconf sync applies all changes in place — hardware, services, and packages patched idempotently, no reinstall.

Private by default

Full-disk LUKS2 encryption, a hardened resolver and kernel sysctls, and no inbound SSH on desktops — the baseline is hardened without being asked.

One CLI for everything

A single hyprconf command drives the whole desktop. A few of the groups — see the README for the full reference.

theme

hyprconf theme <name|next|random|pick|generate> — apply, cycle, or generate themes from an image.

get / set / configure

hyprconf set general border_size 3 — read & write Hyprland options live (hyprctl) and persisted, or browse an interactive REPL.

keybind · rule · monitor

List/add/update keybindings, window & workspace rules, and monitor layouts from the CLI.

lock · idle · paper

Configure hyprlock, hypridle timeouts/actions, and hyprpaper wallpapers.

tui

hyprconf tui — a full-screen terminal UI for themes, keybinds, options, rules, monitors, and system settings.

hardware · doctor · sync · repair

GPU passthrough, on-screen keyboard, auto-rotate, diagnostics, idempotent sync, and self-repair.

yubikey · vpn

FIDO2 hardware-key setup and provider-agnostic VPN management with a fail-closed kill-switch.

utilities

screenshot, record, clipboard, colorpicker, nightlight, gamemode, power, power-profile.

Install

One command starts any path; pick a mode at the prompt.

bash <(curl -fsSL hyprconf.sh)

1 · Full Arch install

  1. Boot an Arch ISO, get online
  2. Run the command above
  3. Pick disk, timezone, hostname, user
  4. Reboot into a themed, encrypted desktop

2 · Dotfiles only

  1. Existing Arch + Hyprland system
  2. Installs packages, stows configs
  3. Enables services
  4. Log out and back in

3 · CLI only

  1. Any Hyprland system
  2. Drops the hyprconf binary in ~/.local/bin
  3. hyprconf --help to start
