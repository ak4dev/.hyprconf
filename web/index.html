.hyprconf

An overlay for Omarchy

One command layers hyprconf's hotkeys, look'n'feel, monitor presets, bar widgets and theme reach onto a stock Omarchy install. Omarchy owns the base system; hyprconf adds one person's preferences on top, only through Omarchy's documented seams — a user theme, shell plugins, hooks, and the override files Omarchy already reads.

One command

bash <(curl -fsSL hyprconf.sh) clones to ~/.hyprconf and applies every stage. Re-running it is idempotent, and updates ride omarchy-update through a post-update hook.

Bar widgets

Omarchy shell plugins: a clock that ticks seconds, only the workspaces in use on two lines with a Pac-Man on the focused one, the focused window's title, CPU/GPU temp and load, RAM/VRAM, up/down.

Theme reach

A Dracula theme in Omarchy's theme menu, and every omarchy theme set also lands in Firefox and Code - OSS.

Keys and VPN

hyprconf-yubikey unlocks the LUKS root with a FIDO2 key at boot. Proton VPN installs from Omarchy's Install → Service menu, the way Omarchy ships NordVPN.

Also: hotkeys with descriptions in SUPER+K · monitor presets on a hotkey · kitty with zsh + Powerlevel10k inside the terminal · a privacy-hardened Firefox policy

install 
$bash <(curl -fsSL hyprconf.sh)

Requires a running Omarchy install.
